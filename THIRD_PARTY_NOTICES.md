# Third-party assets

The game is a native Godot 4 project. No web engine, browser runtime, Unity or Unreal code is used.

## Sport coupe model
- **Ferrari 458 Italia** by **vicent091036**.
- Source: https://sketchfab.com/models/57bf6cc56931426e87494f554df1dab6
- Distributed in the three.js examples: https://github.com/mrdoob/three.js/blob/dev/examples/models/gltf/ferrari.glb
- License: **Creative Commons Attribution 4.0 International** — https://creativecommons.org/licenses/by/4.0/
- Modifications: Draco compression removed for Godot import; mesh simplified with a bounded geometric error; materials replaced/tuned for a satin graphite racing cockpit; wheel and steering nodes reparented at runtime; racing cage, harness, instruments, gated shifter and handbrake added.
- Ferrari and 458 are trademarks of Ferrari S.p.A. This experimental project is not affiliated with or endorsed by Ferrari.
