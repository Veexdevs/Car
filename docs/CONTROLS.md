# Dirigir

1. Segure **FREIO** e arraste o câmbio para **1**.
2. Segure **ACELERAR**. A embreagem assistida acopla a transmissão.
3. Arraste a área **DIREÇÃO** ou toque no volante 3D e arraste.
4. Solte o acelerador para frear com o motor; segure **FREIO** para parar.
5. Para a ré: pare, segure **FREIO**, toque **R** e depois **ACELERAR**.
6. **P** aplica o freio traseiro e reduz a aderência traseira; use com cuidado.
7. Arraste o para-brisa para olhar para o corpo, espelhos e laterais. O botão circular centraliza.

A câmera nunca sai do carro. Não há terceira pessoa, saída do veículo ou troca de personagem.
